# CHAMÉ — Beauty & Skincare

A responsive beauty-store landing page built with React, Vite and Tailwind CSS v4.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open Terminal in the project folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Features

- Responsive announcement bar and navigation with mobile menu
- Editorial skincare hero and promotional sections
- Category cards and product collection
- Add-to-bag interaction with live bag count
- Wishlist toggle interaction
- Testimonials, newsletter form and footer
- Tailwind CSS v4 Vite integration

Images are loaded from Unsplash image CDN URLs and therefore require an internet connection.
